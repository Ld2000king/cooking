# שף בכיס 🍲

אפליקציית מתכונים בעברית (PWA): מתכונים ביתיים, מצב בישול צעד־אחר־צעד עם טיימר, רשימת קניות ויצירת מתכונים משלכם.
עובדת בדפדפן, אפשר להתקין אותה למסך הבית, והיא עובדת גם בלי אינטרנט.

## מה יש באפליקציה

- **מסך פתיחה מונפש** – קמע הסיר נכנס, מקפיץ את המכסה ויוצא (מדלגים בהקשה).
- **התחברות / הרשמה / כניסה כאורח** – עם בדיקת שדות והודעות שגיאה.
- **בית** – המתכון של היום, סינון לפי קטגוריה, שמירה (❤️) והוספה מהירה לרשימת הקניות (+).
- **מתכון** – שינוי מספר מנות שמחשב מחדש את הכמויות, סימון מצרכים, שלבי הכנה.
- **מצב בישול** – שלב אחרי שלב, טיימר לכל שלב שיש בו זמן, החלקה בין שלבים, המסך לא נכבה.
- **יצירת מתכון (+ באמצע)** – אייקון, קטגוריה, רמת קושי, מצרכים ושלבים (שלב עם "25 דקות" מקבל טיימר).
- **חיפוש** – לפי שם, מצרך או קטגוריה.
- **פעילות**, **פרופיל** (המתכונים שלי / שמורים), **רשימת קניות** ו**הגדרות** (כולל מצב כהה).

## עיצוב

- ניווט לפי `topapp`: סרגל תחתון עם 5 טאבים, בית ופרופיל בקצוות (מימין לשמאל), יצירה באמצע, הגדרות בפרופיל.
- תנועה בסגנון Apple (`appledesign`): גיליונות שעולים מלמטה והרקע נדחף אחורה, גרירה לסגירה, תגובה מיידית בלחיצה.
- פתיחה → התחברות → בית לפי `aniapp`, עם קמע מקורי.
- ערכת צבעים לבן־ירוק, מצב כהה, ותמיכה ב־`prefers-reduced-motion`.

## הרצה מקומית

אין צורך בהתקנה – רק שרת סטטי:

```bash
python -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## פרסום ב־GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
אחרי דקה האפליקציה תהיה זמינה ב־`https://ld2000king.github.io/cooking/`.

## הערה על נתונים

אין שרת: החשבון, המתכונים שיצרתם, השמורים ורשימת הקניות נשמרים ב־`localStorage` של המכשיר.
ההתחברות היא מקומית בלבד (לא נשלחת סיסמה לשום מקום), כדי שאפשר יהיה לחבר בהמשך שרת אמיתי (למשל Firebase או Supabase).

## מבנה

```
index.html            מעטפת האפליקציה
css/app.css           כל העיצוב (טוקנים, מצב כהה, אנימציות)
js/main.js            אתחול, מסך פתיחה, התחברות, ניתוב וסרגל ניווט
js/views.js           המסכים: בית, חיפוש, פעילות, פרופיל, מתכון, מצב בישול
js/sheets.js          גיליונות: מתכון חדש, הגדרות, רשימת קניות, עריכת שם
js/ui.js              אייקונים, הקמע, הודעות, גיליון תחתון
js/store.js           שמירת נתונים במכשיר
js/data.js            מתכונים וקטגוריות
sw.js                 עבודה בלי אינטרנט
```
